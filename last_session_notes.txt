  Frequency range used: 1419.2 – 1421.61 MHz (256 bins, ~9.4 kHz/bin)

Calibration / switching:
  Dicke-style noise switching radiometer
  USB relay switches LNA between sky input and internal 50-ohm
  resistor (reference load). Every other spectral record is a
  reference measurement. Sky/reference ratio removes gain drift
  and receiver noise variations.
  Reference rows are flagged with trailing "R" in data files.

DATA FILE FORMAT  (.txt, ezRA/ezCol output)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Line 1:  "from ezCol250313a.py"
Line 2:  lat <deg> long <deg> amsl <m> name <sitename>
Line 3:  freqMin <MHz> freqMax <MHz> freqBinQty <N>
Line 4:  azDeg <deg> elDeg <deg>
Line 5:  "# times are in UTC"
Line 6:  "# gain <dB>"
Lines 7+: Data rows, alternating sky / reference

Data row format:
  <ISO8601 UTC timestamp>  <256 space-separated float values>  [R]
  Trailing "R" = reference (50-ohm load) measurement
  No trailing "R" = sky measurement
  Values are raw power spectral density (relative units)
  Sky/reference ratio gives calibrated antenna temperature proxy.

File naming convention:
  WGA_YYMMDD_HH.txt
  WGA = site prefix (TwoMice_RA → initials/abbrev)
  YYMMDD = date
  HH = approximate start hour (UTC)
  Example: WGA_260627_04.txt = 2026-06-27, starting ~04:00 UTC

Typical file duration: ~6 hours, ~1088 lines (544 sky + 544 ref)
Integration cadence: sky/ref pair every ~20 seconds

STACK-WATERFALL PIPELINE DETAIL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
This is the most developed and most recently worked-on command.
The processing steps in cmd_stack_waterfall() are:

1.  Group input files by elevation (group_by_elevation)
2.  For each elevation group, call sidereal_stack() to align
    spectra by RA and average — SNR improves as sqrt(N_nights)
3.  OPTIONAL bandpass correction (--bandpass-correct flag):
    - Compute median spectrum across all RA rows
    - Fit degree-2 polynomial to shoulder channels only:
        * Exclude outer 15% of band (SDR filter rolloff)
        * Exclude central third of band (HI signal region)
        * Exclude zero-valued channels (RFI-flagged, filled with 0)
          using: valid = fit_mask & np.isfinite(median_spec) & (median_spec > 0.1)
    - Subtract only the AC component of the fit (bandpass - mean)
      so the DC level (~0.595) is preserved for Step 4
    IMPORTANT LESSONS LEARNED (2026-06-28):
    - Division not subtraction: raw data is near 0.595, not near 1.0,
      so dividing by a normalized template doesn't work
    - Must subtract AC component only (bandpass - mean(bandpass))
      to avoid disturbing the DC level that Step 4 relies on
    - Zero-valued channels (RFI-flagged) corrupt the polynomial fit
      and must be explicitly excluded with median_spec > 0.1
    - Edge channels have SDR filter rolloff and must be excluded
      from the fit anchor points
4.  Subtract per-row median to remove DC offset (~0.595 level)
5.  Flag DC-offset RFI columns (column mean outliers, MAD-based)
6.  Flag high-variance RFI columns (erratic columns vs smooth sky)
7.  Interpolate flagged columns from neighbours (column-wise)
8.  Two-pass interpolation for isolated bad pixels (row then column)
9.  Replace any remaining NaN with overall median
10. 3x3 median filter (scipy.ndimage) to remove isolated pixel spikes
11. Set color scale: vmin=-2*noise_sigma, vmax=p99
    Noise estimated from IQR of interior channels only (excludes
    outer 15% to avoid edge artifacts affecting colorscale)
12. Hard clip display to [vmin, vmax]
13. Render with imshow, inferno colormap, dark theme (#0D1117)
14. Mark flagged channels with subtle vertical lines
15. Blue dashed line at v=0 (HI rest velocity)

Session 2026-06-28 work:
  - Added --bandpass-correct flag and full implementation
  - Extensive debugging of bandpass correction approach
  - Key finding: raw calibrated values sit at ~0.595 DC level,
    HI signal is only ~0.017 above that — tiny dynamic range
  - Key finding: zeroed RFI channels corrupt polynomial fit;
    must use (median_spec > 0.1) guard in valid mask
  - Final working approach: AC subtraction on shoulder channels
    with zero exclusion. Works on both El=90° and El=65° stacks.

RADIO ASTRONOMY CONTEXT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
HI rest frequency: 1420.405 MHz (21cm hydrogen line)
Observation mode: drift scan (fixed az/el, sky drifts through beam)
Calibration method: Dicke switching (sky vs 50-ohm reference)
Velocity convention: LSR (Local Standard of Rest)
Bright calibrator sources:
  Cas A: ~2700 Jy at 1420 MHz
  Cyg A: ~1600 Jy at 1420 MHz  ← current target
  Tau A: ~900 Jy at 1420 MHz
  Vir A: ~210 Jy at 1420 MHz

Sidereal stacking rationale:
  Each night the sky drifts through the beam at the same sidereal
  rate. Aligning records by RA (sidereal time) and averaging N nights
  improves SNR by sqrt(N). Three nights → sqrt(3) ≈ 1.73x improvement.
